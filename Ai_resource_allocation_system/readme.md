# 🚀 Startup Resource Allocator

A data-driven decision support system designed for startups to optimize resource allocation across competing internal requests (Features, Bugs, Debt, Customer Requests).

## 🌟 Key Features

- **Weighted Scoring Algorithm:** Prioritizes tasks based on Impact, Urgency, and Strategic Value relative to Effort.
- **Capacity Constraints:** Defines sprint capacity to prevent over-commitment.
- **Visual Analytics:** Interactive charts showing allocation status and effort/value matrices.
- **Trade-off Analysis:** Identifies "Quick Wins" (High Value, Low Effort) vs. "Money Pits".
- **Exportable Reports:** Download prioritized lists for stakeholder meetings.

## 🛠️ Tech Stack

- **Frontend:** Streamlit
- **Data Processing:** Pandas
- **Visualization:** Plotly
- **Database:** SQLite (Local, Serverless)
